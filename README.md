# 🌍 TravelShowcase

A modern, premium frontend web application to showcase travel destinations with stunning UI, smooth animations, and responsive design.

🔗 **Live Demo:**
https://travel-showcase.vercel.app

---

## 📌 Overview

TravelShowcase is a fully responsive React-based frontend project designed to present travel destinations in a visually appealing gallery format.

The application focuses on **UI/UX excellence**, smooth animations, and clean component architecture, making it ideal for showcasing frontend development skills.

---

## ✨ Features

* 🌐 Beautiful Landing Page with Hero Section
* 🖼️ Interactive Gallery with Category Filters
* ⚡ Smooth Animations using Framer Motion
* 🌙 Dark Mode Support
* 📱 Fully Responsive Design
* 🧭 Multi-page Navigation (React Router)
* 📩 Contact Page with Form UI
* 🎨 Modern Glassmorphism & Gradient UI

## 🚀 Key Functionalities

### 🔹 Gallery Filtering

Users can filter travel destinations based on categories like:

* Asia
* Europe
* Americas
* Africa
* Oceania

Dynamic filtering is handled using React state.

---

### 🔹 Dark Mode Toggle

Implemented using:

* React state
* `document.documentElement.classList`

---

### 🔹 Animations

* Page transitions
* Hover effects
* Stagger animations
* Smooth scaling & motion effects

Powered by **Framer Motion**.

## ⚙️ Installation & Setup

```bash
# Clone the repository
git clone https://github.com/your-username/travel-showcase.git

# Navigate to project folder
cd travel-showcase

# Install dependencies
npm install

# Run development server
npm run dev
```
